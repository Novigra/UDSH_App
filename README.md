<h1><br>Utility Dialogue System Hamo</h1>
<p>UDSH is a screenwriting software for video game development. It's built to enhance the workflow and pipeline of story development.</p>
<p>If you're going to use it, please let me know what you think of it.</p>

<h2>Installation</h2>
<p>There's no installation process. You can just download it and start the app through UDSH.exe</p>

<h2>OS</h2>
<p>The application only supports Windows.</p>

<h2>Plugin</h2>
<p>The application also has plugins to help you with the development. Currently the only supported engine in Unreal Engine. Expect Unity and Godot soon.</p>
